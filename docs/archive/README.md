# Documentation Archive

This folder is for reversible documentation cleanup.

Move files here only after human approval. Do not use it to hide active architecture decisions, API contracts, schema notes, security notes, deployment notes, or roadmap items.

When a file moves here, keep or add a short note in `docs/context-index.md` that says what replaced it and when to load the archived source.

Current archive groups:

- `historical/`: long historical docs replaced by compact pointer pages at their old paths.
- `session-notes/`: old handoff and repository-state notes.
